# 음료 병뚜껑 OK/NG 자동 판정 실험 계획서

> 모바일로 촬영한 음료 병 이미지에서 **뚜껑 유무**를 규칙 기반 머신비전(OpenCV)으로 판정한다.
> 프로젝트 폴더: `~/ai_vision/subject9_machinevision`

---

## 1. 문제 정의

| 항목 | 내용 |
|---|---|
| 검사 대상 | 음료(PET) 병의 뚜껑 |
| 입력 | 휴대폰으로 촬영한 병 상단 이미지 1장 |
| 출력 | `OK`(뚜껑 있음) / `NG`(뚜껑 없음) + 판정 근거 수치 |
| 방식 | 규칙 기반: ROI → 전처리 → 이진화 → Morphology → Contour 측정 → 규칙 판정 |

### 1.1 OK / NG 정의

| 판정 | 정의 | 이번 실험 포함 여부 |
|---|---|---|
| OK | 뚜껑이 끝까지 닫혀 있음 | 포함 |
| NG | 뚜껑 없음 | 포함 |

### 1.2 오류의 의미 (비즈니스 관점)

| 오류 | 상황 | 영향 | 우선순위 |
|---|---|---|---|
| **FN (미탐)** | 뚜껑 없음(NG)을 OK로 판정 | 불량품이 고객에게 출고됨 | **가장 치명적 → 0건 목표** |
| **FP (오탐)** | 뚜껑 있음(OK)을 NG로 판정 | 정상품 폐기 / 재검 비용 | 낮을수록 좋음 |

> 판정이 기준 근처로 애매하면 자동 판정하지 않고 **재검사(REVIEW)** 로 분류하는 것도 고려한다.

## 2. 데이터 계획

### 2.1 수량 및 역할

| 폴더 | OK | NG | 역할 |
|---|---|---|---|
| `data/calibration` | 10 | 10 | 기준(ROI, 임계값, 판정 기준)을 **정할 때만** 사용 |
| `data/validation` | 5~10 | 5~10 | 정한 기준을 **중간 점검** |
| `data/test` | 10 | 10 | 기준 **고정 후 단 한 번** 최종 채점 |
| `data/challenge` | 5 | 5 | 일부러 어려운 조건 (역광, 어두움, 위치 이동, 다른 배경) |

- 병 종류 2~3가지를 섞는다.
- 가능하면 **병 단위로** 폴더를 나눈다. (같은 병 사진이 calibration과 test에 동시에 들어가지 않게)

### 2.2 촬영 조건 (calibration / validation / test 공통 고정)

- [ ] 배경: 단색 밝은 배경 (흰 종이 / 벽)
- [ ] 폰 위치·높이·거리 고정 (거치대 또는 책 쌓기)
- [ ] 병 놓는 위치 테이프로 표시 (지그)
- [ ] 같은 장소, 같은 조명, 같은 시간대
- [ ] 줌 1배, 플래시 OFF, HDR / 인물 모드 OFF

challenge 데이터에서만 조건을 의도적으로 바꾼다.

### 2.3 파일 이름 규칙

```
{정답}_{병종류}_{조건}_{번호}.jpg

ok_bottleA_normal_01.jpg
ng_bottleB_normal_03.jpg
ok_bottleA_dark_01.jpg      ← challenge
ng_bottleC_shift_02.jpg     ← challenge
```

### 2.4 데이터 기록 (`reports/dataset_roles.csv`)

| 컬럼 | 설명 | 예시 |
|---|---|---|
| file | 파일 이름 | ok_bottleA_normal_01.jpg |
| label | 정답 | OK / NG |
| role | 역할 | calibration / validation / test / challenge |
| bottle | 병 종류 | bottleA |

| note | 비고 (제외 사유 등) | 흔들림으로 제외 |

## 3. 처리 흐름 (파이프라인)

```
입력 이미지
   ↓
① ROI          뚜껑 자리만 자르기 (아래 넥 링 제외)
   ↓
② 전처리        그레이스케일 → 대비 보정
   ↓
③ 이진화        뚜껑(어두움)을 흰색으로 (THRESH_BINARY_INV)
   ↓
④ Morphology   Opening으로 나사산 등 가는 잡음 제거
   ↓
⑤ Contour 측정  가장 큰 덩어리의 면적 / 폭 / 가로세로 비율
   ↓
⑥ 규칙 판정     측정값 ≥ 기준 → OK, 미만 → NG
```

### 3.1 고정 파라미터 기록 (Rule Freeze)

| 파라미터 | 값 | 정한 근거 | 코드 위치 |
|---|---|---|---|
| ROI | 기준 이미지 전체 (뚜껑 + 넥 링 포함) | 1일차 ROI로 이미 잘린 이미지라 추가 자르기 없음 | - |
| 대비 보정 | 사용 안 함 | 고정 T=50 + min-max가 테스트 6장에서 3/6 (조명 변화에 약함) | - |
| 이진화 | Otsu + THRESH_BINARY_INV | 테스트 6장에서 뚜껑을 안정적으로 분리 | `binarize()` |
| Morphology | 타원 3×3, Opening 1회 → Closing 1회 | 교재 3일차 커널 비교 결론 | `KERNEL_SIZE = 3` |
| 판정 특징 | 위쪽 절반의 꽉 찬 줄 비율 | 면적 비율은 병 거리 변화에 흔들림 (마진 0.121 → 0.414) | `solid_row_ratio()` |
| 꽉 찬 줄 기준 | fill = 0.5 | 0.3~0.6 모두 6/6, 0.7부터 붕괴 → 안정 구간 가운데 선택 | `FILL = 0.5` |
| 판정선 | 0.601 (기준 ON 0.869와 OFF 0.333의 중간) | 교재 규칙: 기준 2장의 중간값 | `load_rule()` |
| CHECK 구간 | 0.547 ~ 0.655 | 임의 설정 (ON−OFF 간격의 ±10%), 실촬영 후 재검토 | `REVIEW_BAND = 0.10` |
| ROI 유효성 | 흰색 비율 1% ~ 99% | 임의 설정, 빈 화면·배경만 찍힌 경우 거르기 | `MIN_WHITE`, `MAX_WHITE` |
| 고정 일시 | 2026-10-27 | 기준 2장 + 강사 테스트 6장(validation) | - |
| 2026-10-27 | Otsu (고정값 폐기) | 강사 테스트 6장에서 T=50은 3/6. 테스트 뚜껑 밝기 p5가 25→54로 올라가 못 잡음 | 기준 1쌍 + 테스트 6장 |

## 4. 사전 실험 결과 (2일차, 기준 이미지 1쌍)

> `cap_on_reference.jpg` / `cap_off_reference.jpg` 및 대비를 낮춘 `low_contrast.jpg`로 진행한 사전 실험.
> 실제 촬영 데이터에서 다시 검증이 필요하다.

### 4.1 대비 보정 / 노이즈 제거 비교

원본(on)의 Otsu 이진화 결과를 정답으로 두고 일치율 비교

| 방법 | Otsu 임계값 | 정답과 일치율 |
|---|---|---|
| min-max 정규화만 | 118 | **99.80%** |
| min-max + Bilateral (d=15, σColor=55, σSpace=5) | 120 | 99.00% |
| min-max + Gaussian (5×5) | 119 | 98.95% |

**결론:** `low_contrast`는 대비만 낮아진 이미지라 노이즈 제거가 오히려 경계를 바꿈 → **min-max 정규화만 사용**

### 4.2 고정 임계값 vs Otsu (전체 이미지)

| 방법 | ON 흰 비율 | OFF 흰 비율 | 차이 |
|---|---|---|---|
| 고정 T=90 | 61.7% | 36.1% | **25.6%p** |
| Otsu | 65.0% (T=122) | 48.7% (T=133) | 16.3%p |

**결론:** Otsu는 뚜껑이 없는 OFF에서도 억지로 둘로 나누며 임계값이 133으로 올라가 나사산·유리까지 흰색으로 잡음 → **고정 임계값이 유리**

### 4.3 ROI 적용 (y 20~90, x 20~195)

| 방법 | ON 흰 비율 | OFF 흰 비율 | 차이 |
|---|---|---|---|
| 고정 T=90 | 99.7% | 27.2% | **72.5%p** |
| Otsu | 99.7% (T=104) | 54.7% (T=137) | 45.0%p |

**결론:** ROI로 아래 넥 링을 제외하자 차이가 25.6%p → 72.5%p로 증가.
**남은 문제:** OFF에서 나사산이 27.2% 잡힘 → Morphology + 가장 큰 덩어리 면적으로 해결 예정.

### 4.4 사전 실험의 한계

- 기준 이미지 **1쌍**에서 변형해 만든 결과라 일반화 근거가 약함
- ROI 좌표를 눈으로 정해 병 위치가 바뀌면 깨질 수 있음
- 흰 픽셀 **비율**은 모양을 보지 않아 흩어진 잡음에 속을 수 있음

## 8. 확장 가능성

- **김치 갈변 검사:** 같은 흐름(ROI → 이진화 → Morphology → Contour → 비율 판정)에서 그레이스케일 대신 **HSV / Lab 색 범위 이진화** 사용
  - 나뭇가지와의 구별: 길쭉한 정도, Solidity, 경계 선명도, 내부 색 균일도
- **이상검출(7일차)과 결합:** 정상 이미지 기준으로 벗어난 부분을 찾아 규칙 검사와 함께 최종 판정 (Hybrid)
