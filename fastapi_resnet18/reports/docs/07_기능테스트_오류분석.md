## 4. 관찰 사항

- **콜드 스타트:** 컨테이너 첫 추론은 web 2,155.39ms, worker 2,148.14ms. 이후 18~22ms. 모델을 각 프로세스에서 처음 불러오기 때문이다.
- **캐시 만료:** 15:01에 보낸 이미지를 16:05에 다시 보내자 `cache_hit false` — Redis 캐시 보관시간(600초)이 지나 정상적으로 만료되었다.
- **`running` 미관찰:** 작업이 수십 ms 안에 끝나 화면에서 `running`을 보지 못했다. 정상 완료는 최종 `done`, DB 행, Worker 로그로 판단했다.
